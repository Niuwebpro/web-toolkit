# Web Toolkit

Utilitaires web autonomes et outils WordPress, regroupés par usage.

| Partie | Projet | Téléchargement |
| --- | --- | --- |
| [Autonome](standalone/) | [Tailwind Dark Mode Toggle](standalone/tailwind-dark-mode-toggle/) — HTML, CSS et JavaScript | [ZIP autonome](standalone/downloads/tailwind-dark-mode-toggle.zip) |
| [WordPress](wordpress/) | [Bouton mode sombre](wordpress/plugins/dark-mode-toggle/) — bloc Gutenberg et shortcode | [ZIP installable](wordpress/downloads/dark-mode-toggle-0.1.0.zip) |

Le projet autonome s’ouvre dans un navigateur. Seul le ZIP de l’extension WordPress s’installe dans WordPress ; le ZIP de tout le dépôt ne s’y installe pas.

## Organisation

- `standalone/` : projets indépendants de WordPress et leurs téléchargements.
- `wordpress/plugins/` : extensions WordPress.
- `wordpress/snippets/` : extraits à appliquer manuellement dans WordPress.
- `wordpress/docs/` : installation, architecture et validation WordPress.
- `wordpress/scripts/` : fabrication des ZIP WordPress.
- `wordpress/tests/` : tests des utilitaires WordPress.
- `wordpress/downloads/` : extensions prêtes à télécharger.
